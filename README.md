# Crossword Game

## 1. Опис на апликацијата
 Апликацијата претставува дигитална верзија на класичната игра крстозбор
 каде играчот треба да ги пополни полињата со точни букви врз основа на дадени hints.

 Апликацијата се состои од два екрани - почетен екран за започнување на 
 играта и главен екран со крстозборот.

 ### Функционалности
• Хинтови за секој збор прикажани на левата страна
• Копче Check за проверка на точноста на внесените букви
• Копче Hint за откривање на случајна буква
• Копче New за генерирање на нов крстозбор
• Движење низ полињата 
• Бришење на букви

## 2. Решение на проблемот
### Податоци и структури
 Податоците се чуваат во три класи:
 Word - чува информации за еден збор(самиот збор, хинтот, почетен ред, почетна колона, дали зборот е хоризонтален или вертикален)
 CrosswordBoard - ја чува целата логика на играта:
 - Solution[15,15] - матрица со точните букви
 - UserGrid[15,15] - матрица со она што го внел играчот
 - Words - листа на Word објекти
 - AllPuzzles - листа од листи, каде надворешната листа ги претставува сите puzzles, а секоја внатрешна листа ги содржи зборовите што припаѓаат на еден крстозбор
 Game - го чува UI делот:
 - cells[15,15] - матрица од TextBox (едно поле = една буква)
 - board - инстанца на CrosswordBoard
 - cluesPanel - панел за прикажување хинтови

## 3. Опис на функција
 Функцијата GenerateNew() во CrosswordBoard.cs го исчистува досегашниот крстозбор и избира случаен (од веќе креираните три)
 public void GenerateNew()
{
    for (int i = 0; i < Size; i++)
        for (int j = 0; j < Size; j++)
        {
            Solution[i, j] = ' ';
            UserGrid[i, j] = ' ';
        }

    Words.Clear();

    int next = lastPuzzleIndex;
    while (next == lastPuzzleIndex && AllPuzzles.Count > 1)
        next = Random.Next(AllPuzzles.Count);

    lastPuzzleIndex = next;
    var puzzle = AllPuzzles[next];

    foreach (var word in puzzle)
    {
        Words.Add(word);
        for (int i = 0; i < word.WordName.Length; i++)
        {
            int r = word.IsHorizontal ? word.StartRow : word.StartRow + i;
            int c = word.IsHorizontal ? word.StartCol + i : word.StartCol;
            Solution[r, c] = word.WordName[i];
        }
    }
}
Функцијата прво ги чисти Solution и UserGrid. Потоа во while избира случаен индекс кој е различен од претходниот за да се осигураме дека секогаш се прикажува различен крстозбор. На крај за секој збор од избраниот крстозбор, буква по буква ја запишува во Solution на точната позиција врз основа на тоа дали зборот е хоризонтален или вертикален.

## 4. Упатство за користење
 На почетниот прозорец имаме копче за започнување на играта (Start Game). Потоа ни се појавува екранот на слика 2. 

 На левата страна се прикажани хинтовите. Бројот и стрелката покажуваат кој збор е хоризонтален а кој вертикален.

 Со кликање на некое поле може да започнеме со пишување. Курсорот автоматски скока на следното поле. Исто така, може да ги користиме и стрелките на тастатурата за движење низ полињата.

 Backspace ја брише тековната буква и оди на претходното поле.

 Со кликање на копчето Check проверуваме колку букви ни се точни. Зелено = точно, црвено = грешно.

 Со кликање на Hint се открива случајна буква (жолта боја).

 Со кликање на New се појавува различен крстозбор.
